# Security Policy — NetGraph

## Supported Versions

Only the latest main branch release receives security updates and patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x (`main`) | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of NetGraph seriously. If you discover a security vulnerability, please do **NOT** open a public issue.

Instead, please report it via:
- **GitHub Private Advisory**: Submit a private report via the [Security Tab](https://github.com/mohit-dhiman-cs/NetGraph-Enterprise-Grade-Social-Networking-Platform/security/advisories/new)
- **Email**: Send details directly to `dhimanmohit589@gmail.com` (or your preferred contact email)

### What to Include
- Description of the issue & potential impact
- Step-by-step reproduction / Proof-of-Concept (PoC)
- Affected endpoints or components (e.g., Auth, REST API, WebSockets)

### What to Expect
- **Response Time**: We will acknowledge your report within 48 hours.
- **Status Updates**: Progress updates every 3–5 business days until a fix is released.
